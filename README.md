<h2>🚀 Core Features</h2>
<h3>📂 Universal Tracking</h3>
Forget fragmented lists. Akasha tracks it all in one place:
<ul>
  <li>Screens: Movies, TV Shows, and Anime.</li>
  <li>Readings: Mangas, Manhwas (Webtoons), and Books.</li>
  <li>States: Watching, Planning, Completed, On Hold, and Favorites.</li>
</ul>
<h3>🔗 Serverless Sharing</h3>
Share your favorites without complexity.
<ul>
  <li>Encoded Links: Media data is transported directly within the URL using Base64 encoding—no public database queries required for guests.</li>
  <li>Guest View: Recipients without an account see an elegant landing page promoting your curation and the Akasha platform.</li>
</ul>
<h3>📱 Native Feel & PWA</h3>
<ul>
  <li>Installation: Add Akasha to your home screen for a full-screen, app-like experience.</li>
  <li>Push Notifications: Stay updated with release alerts for your tracked series and chapters.</li>
  <li>Navigation: Full support for mobile hardware "Back" buttons via Hash Routing.</li>
</ul>
<h3>🌍 Global Sync & Intelligence</h3>
<ul>
  <li>Deep Integration: Connected to TMDB, AniList, Shikimori, and OpenLibrary.</li>
  <li>Multilingual: Fully localized in English and French.</li>
  <li>Manual Control: Add custom entries for rare gems that aren't in the global databases.</li>
</ul>
<h3>🛠 Technical Stack</h3>
<ul>
  <li>Frontend: React + TypeScript</li>
  <li>Styling: Tailwind CSS</li>
  <li>Backend: Supabase (Auth, PostgreSQL, Row Level Security)</li>
  <li>Icons: Lucide React</li>
  <li>Security: hCaptcha integration for bot protection</li>
</ul>
